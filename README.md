# Fale Confiante

Aplicação mobile-first para treino diário de comunicação e oratória.

## Funcionalidades desta primeira versão

- Programa de 30 dias com 30 lições.
- Leitura das lições por voz com Web Speech API em pt-PT.
- Gravação e reprodução de exercícios com MediaRecorder.
- Histórico e progresso guardados localmente.
- Treinador virtual em modo local, preparado para integração futura com IA segura.
- Navegação mobile com Início, Aprender, Treinar, Treinador e Biblioteca.
